# Yun Sun — personal academic homepage

This folder contains a static, photo-free personal website for Yun Sun. It is plain HTML, CSS, and JavaScript, so it can be published directly with GitHub Pages.

## Publish at `sunyun-whut.github.io`

1. Create a **public** repository named `sunyun-whut.github.io` on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` from this folder to the repository root.
3. Open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will publish the site at `https://sunyun-whut.github.io` after the deployment finishes.

The site intentionally omits the phone number from the CV. Add it only if you want that information public.
